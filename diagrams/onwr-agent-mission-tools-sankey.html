ONWR / AGENT RELATIONSHIP MAP

13 ภารกิจ → Agent → เครื่องมือ

แผนภาพความเชื่อมโยงแบบ Sankey-style รวมครบในภาพเดียว โดย Agent หลักรับโจทย์และเลือก Sub-agent ตามภารกิจ สามารถประสานหลายด้านสำหรับโจทย์เดียวได้

เส้นมีความหนาเท่ากันเพื่อแสดงความสัมพันธ์เท่านั้น ไม่ใช่ Sankey เชิงปริมาณ และไม่ได้หมายถึงเรียกใช้ทุกเครื่องมือในทุกครั้ง
MCP ทั้ง 3 ระบบเป็นข้อเสนอระยะออกแบบ ยังไม่ได้เชื่อมต่อฐานข้อมูลจริง

มอบหมายงาน / เรียกใช้ MCP ตามความจำเป็น เข้าถึงคลังองค์ความรู้กลางร่วมกัน

ชื่อ Sub-agent บางรายการย่อเพื่อการจัดหน้า ตรวจชื่อภารกิจฉบับเต็มได้ในตารางด้านล่าง เส้นที่ตัดกันไม่ได้หมายถึงการเชื่อมต่อกัน

ความเชื่อมโยงที่ตรวจสอบได้

รหัส ภารกิจ Agent เครื่องมือ
KM-01 นโยบายและแผนบริหารจัดการน้ำ Agent หลัก → Sub-agent KM-01 คลังองค์ความรู้กลาง + MCP-02
KM-02 บูรณาการแผนงานและงบประมาณ Agent หลัก → Sub-agent KM-02 คลังองค์ความรู้กลาง + MCP-02, MCP-03
KM-03 บริหารจัดการน้ำระดับลุ่มน้ำ Agent หลัก → Sub-agent KM-03 คลังองค์ความรู้กลาง + MCP-01, MCP-03
KM-04 กฎหมายและระเบียบด้านทรัพยากรน้ำ Agent หลัก → Sub-agent KM-04 คลังองค์ความรู้กลาง
KM-05 งานเลขานุการคณะกรรมการ Agent หลัก → Sub-agent KM-05 คลังองค์ความรู้กลาง
KM-06 การมีส่วนร่วมและเครือข่ายผู้ใช้น้ำ Agent หลัก → Sub-agent KM-06 คลังองค์ความรู้กลาง
KM-07 สถานการณ์น้ำ ข้อมูลสารสนเทศทรัพยากรน้ำ และผังน้ำ Agent หลัก → Sub-agent KM-07 คลังองค์ความรู้กลาง + MCP-01, MCP-03
KM-08 ติดตามและประเมินผลแผนงานและแผนแม่บท Agent หลัก → Sub-agent KM-08 คลังองค์ความรู้กลาง + MCP-01, MCP-02
KM-09 บริหารจัดการนวัตกรรม Agent หลัก → Sub-agent KM-09 คลังองค์ความรู้กลาง
KM-10 ความร่วมมือระหว่างประเทศ Agent หลัก → Sub-agent KM-10 คลังองค์ความรู้กลาง
KM-11 งานเลขานุการ ธุรการ และพัสดุ Agent หลัก → Sub-agent KM-11 คลังองค์ความรู้กลาง
KM-12 งานประชาสัมพันธ์ Agent หลัก → Sub-agent KM-12 คลังองค์ความรู้กลาง
KM-13 งานพัฒนาระบบบริหารและบริหารงานบุคคล Agent หลัก → Sub-agent KM-13 คลังองค์ความรู้กลาง

Agent หลักสังเคราะห์คำตอบโดยรักษาแหล่งอ้างอิงและข้อจำกัด ผู้รับผิดชอบตรวจสอบข้อเสนอและพิจารณาตัดสินใจตามอำนาจหน้าที่
