Agent หลักเลือก Sub-agent ได้มากกว่าหนึ่งด้านตามโจทย์ ทุกด้านใช้คลังองค์ความรู้กลาง ส่วน MCP ระบุเฉพาะความเชื่อมโยงที่มีในเอกสารโครงการ

รหัส ภารกิจ ผู้รับงาน เครื่องมือที่ใช้
KM-01 นโยบายและแผนบริหารจัดการน้ำ Sub-agent KM-01 คลังองค์ความรู้กลาง + MCP-02
KM-02 บูรณาการแผนงานและงบประมาณ Sub-agent KM-02 คลังองค์ความรู้กลาง + MCP-02 + MCP-03
KM-03 บริหารจัดการน้ำระดับลุ่มน้ำ Sub-agent KM-03 คลังองค์ความรู้กลาง + MCP-01 + MCP-03
KM-04 กฎหมายและระเบียบด้านทรัพยากรน้ำ Sub-agent KM-04 คลังองค์ความรู้กลาง
KM-05 งานเลขานุการคณะกรรมการ Sub-agent KM-05 คลังองค์ความรู้กลาง
KM-06 การมีส่วนร่วมและเครือข่ายผู้ใช้น้ำ Sub-agent KM-06 คลังองค์ความรู้กลาง
KM-07 สถานการณ์น้ำ ข้อมูลสารสนเทศทรัพยากรน้ำ และผังน้ำ Sub-agent KM-07 คลังองค์ความรู้กลาง + MCP-01 + MCP-03
KM-08 ติดตามและประเมินผลแผนงานและแผนแม่บท Sub-agent KM-08 คลังองค์ความรู้กลาง + MCP-01 + MCP-02
KM-09 บริหารจัดการนวัตกรรม Sub-agent KM-09 คลังองค์ความรู้กลาง
KM-10 ความร่วมมือระหว่างประเทศ Sub-agent KM-10 คลังองค์ความรู้กลาง
KM-11 งานเลขานุการ ธุรการ และพัสดุ Sub-agent KM-11 คลังองค์ความรู้กลาง
KM-12 งานประชาสัมพันธ์ Sub-agent KM-12 คลังองค์ความรู้กลาง
KM-13 งานพัฒนาระบบบริหารและบริหารงานบุคคล Sub-agent KM-13 คลังองค์ความรู้กลาง
